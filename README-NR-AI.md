# NR AI Assistant — Local / No API

The portfolio includes a completely local **NR AI Assistant**.

- No OpenAI API key is required.
- No external API calls are made.
- No serverless backend is required.
- The assistant uses a small local rule-based knowledge layer for common questions about the public portfolio.
- Private K-Vault article content is not returned by the assistant.

This makes the portfolio suitable for static hosting such as GitHub Pages.
